# DeliveryOptimization Module
## Description
Use the DeliveryOptimization cmdlets to monitor downloads and performance, configure download modes and bandwidth limits, manage cached files, and troubleshoot Delivery Optimization.

## DeliveryOptimization Cmdlets
### [Delete-DeliveryOptimizationCache](Delete-DeliveryOptimizationCache.md)
Deletes files from the Delivery Optimization cache and removes their associated persisted data.

### [Disable-DeliveryOptimizationVerboseLogs](Disable-DeliveryOptimizationVerboseLogs.md)
Disables verbose logging for Delivery Optimization.

### [Enable-DeliveryOptimizationVerboseLogs](Enable-DeliveryOptimizationVerboseLogs.md)
Enables verbose logging for Delivery Optimization.

### [Get-DeliveryOptimizationPerfSnap](Get-DeliveryOptimizationPerfSnap.md)
Gets a snapshot of Delivery Optimization performance statistics.

### [Get-DeliveryOptimizationPerfSnapThisMonth](Get-DeliveryOptimizationPerfSnapThisMonth.md)
Gets Delivery Optimization performance statistics for the current calendar month.

### [Get-DeliveryOptimizationStatus](Get-DeliveryOptimizationStatus.md)
Gets a real-time snapshot of current Delivery Optimization jobs.

### [Get-DOConfig](Get-DOConfig.md)
Gets the local configuration and policies applied to Delivery Optimization.

### [Get-DODownloadMode](Get-DODownloadMode.md)
Gets the current Delivery Optimization download mode.

### [Get-DOPercentageMaxBackgroundBandwidth](Get-DOPercentageMaxBackgroundBandwidth.md)
Gets the maximum percentage of available bandwidth that Delivery Optimization can use for background downloads.

### [Get-DOPercentageMaxForegroundBandwidth](Get-DOPercentageMaxForegroundBandwidth.md)
Gets the maximum percentage of available bandwidth that Delivery Optimization can use for foreground downloads.

### [Set-DeliveryOptimizationStatus](Set-DeliveryOptimizationStatus.md)
Sets the expiration time or pinning status of files in the Delivery Optimization cache.

### [Set-DODownloadMode](Set-DODownloadMode.md)
Sets the Delivery Optimization download mode.

### [Set-DOMaxBackgroundBandwidth](Set-DOMaxBackgroundBandwidth.md)
Sets the maximum bandwidth, in KB/s, that Delivery Optimization can use for background downloads.

### [Set-DOMaxForegroundBandwidth](Set-DOMaxForegroundBandwidth.md)
Sets the maximum bandwidth, in KB/s, that Delivery Optimization can use for foreground downloads.

### [Set-DOPercentageMaxBackgroundBandwidth](Set-DOPercentageMaxBackgroundBandwidth.md)
Sets the maximum percentage of available bandwidth that Delivery Optimization can use for background downloads.

### [Set-DOPercentageMaxForegroundBandwidth](Set-DOPercentageMaxForegroundBandwidth.md)
Sets the maximum percentage of available bandwidth that Delivery Optimization can use for foreground downloads.

### [Get-DeliveryOptimizationLog](Get-DeliveryOptimizationLog.md)
Gets Delivery Optimization log entries as PowerShell objects.

### [Get-DeliveryOptimizationLogAnalysis](Get-DeliveryOptimizationLogAnalysis.md)
Analyzes Delivery Optimization logs to summarize download activity and peering efficiency.
